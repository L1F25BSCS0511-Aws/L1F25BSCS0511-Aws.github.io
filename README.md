## 🚀 How to Run Locally

### Option 1: Direct Browser Launch
Simply double-click `index.html` to open it in your browser!

### Option 2: Local HTTP Server (Recommended)
From the project folder, run:
```bash
# Using Node.js npx:
npx serve . -p 3000

# Or using Python:
python -m http.server 3000
```
Then navigate to `http://localhost:3000` in your browser.

## 🌐 How to Deploy to GitHub Pages / awshameed.me

Since this project is built with clean, zero-build static architecture, deploying to GitHub Pages is instant:

1. **Copy or Commit files to your GitHub repository**:
   ```bash
   git init
   git add .
   git commit -m "feat: Recreate full animated portfolio v2.0"
   ```

2. **Push to your GitHub repository** (e.g. `L1F25BSCS0511-Aws/L1F25BSCS0511-Aws.github.io` or your custom domain repo):
   ```bash
   git remote add origin https://github.com/L1F25BSCS0511-Aws/<your-repo-name>.git
   git branch -M main
   git push -u origin main
   ```

3. **Enable GitHub Pages**:
   - Go to your repository settings on GitHub: **Settings** → **Pages**.
   - Under **Build and deployment** > **Branch**, select `main` (or `master`) and `/ (root)`.
   - Click **Save**.
   - Your updated site will be live at `https://awshameed.me` (or `https://L1F25BSCS0511-Aws.github.io`)!
